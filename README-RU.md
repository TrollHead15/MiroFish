## ⚡ Обзор

**MiroFish** — это ИИ-движок прогнозирования нового поколения, работающий на основе мультиагентных технологий. Извлекая исходные данные из реального мира (например, срочные новости, проекты законов или финансовые сигналы), система автоматически создаёт высокоточный параллельный цифровой мир. В этом пространстве тысячи интеллектуальных агентов с независимыми личностями, долговременной памятью и поведенческой логикой свободно взаимодействуют и проходят социальную эволюцию. Вы можете динамически вводить переменные с «позиции всевидящего ока», чтобы точно моделировать будущие траектории — **репетировать будущее в цифровой песочнице и принимать решения после бесчисленных симуляций**.

> Вам нужно лишь: загрузить исходные материалы (аналитические отчёты или интересные художественные сюжеты) и описать ваши требования к прогнозу на естественном языке</br>
> MiroFish вернёт: детальный прогнозный отчёт и глубоко интерактивный высокоточный цифровой мир

### Наше видение

MiroFish стремится создать зеркало роевого интеллекта, отображающее реальность. Фиксируя коллективные эффекты, возникающие в результате взаимодействия индивидов, мы преодолеваем ограничения традиционного прогнозирования:

- **На макроуровне**: Мы — лаборатория репетиций для лиц, принимающих решения, где политики и пиар-стратегии можно тестировать с нулевым риском
- **На микроуровне**: Мы — творческая песочница для отдельных пользователей — будь то моделирование финалов романов или исследование воображаемых сценариев, всё может быть увлекательным, игровым и доступным

От серьёзных прогнозов до развлекательных симуляций — мы позволяем каждому «а что, если» увидеть свой исход, делая возможным предсказание чего угодно.

## 🔄 Рабочий процесс

1. **Построение графа**: Извлечение исходных данных & Инъекция индивидуальной/коллективной памяти & Построение GraphRAG
2. **Настройка среды**: Извлечение связей между сущностями & Генерация персонажей & Инъекция конфигурации агентов
3. **Симуляция**: Параллельная симуляция на двух платформах & Автопарсинг требований к прогнозу & Динамическое обновление временной памяти
4. **Генерация отчёта**: ReportAgent с богатым набором инструментов для глубокого взаимодействия с пост-симуляционной средой
5. **Глубокое взаимодействие**: Чат с любым агентом в смоделированном мире & Взаимодействие с ReportAgent

## 🚀 Быстрый старт

### Вариант 1: Развёртывание из исходного кода (рекомендуется)

#### Требования

| Инструмент | Версия | Описание | Проверка установки |
|------|---------|-------------|-------------------|
| **Node.js** | 18+ | Среда выполнения фронтенда, включает npm | `node -v` |
| **Python** | ≥3.11, ≤3.12 | Среда выполнения бэкенда | `python --version` |
| **uv** | Последняя | Менеджер пакетов Python | `uv --version` |

#### 1. Настройка переменных окружения

```bash
# Скопируйте пример конфигурационного файла
cp .env.example .env

# Отредактируйте файл .env и заполните необходимые API-ключи
```

**Необходимые переменные окружения:**

```env
# Конфигурация API LLM (поддерживается любой LLM API с форматом OpenAI SDK)
# Рекомендуется: модель Alibaba Qwen-plus через платформу Bailian: https://bailian.console.aliyun.com/  
# Высокое потребление — начните с симуляций менее 40 раундов
LLM_API_KEY=ваш_api_ключ
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1  
LLM_MODEL_NAME=qwen-plus

# Конфигурация Zep Cloud
# Бесплатного месячного лимита достаточно для простого использования: https://app.getzep.com/  
ZEP_API_KEY=ваш_zep_api_ключ
```

#### 2. Установка зависимостей

```bash
# Установка всех зависимостей в один клик (root + фронтенд + бэкенд)
npm run setup:all
```

Или пошаговая установка:

```bash
# Установка Node-зависимостей (root + фронтенд)
npm run setup

# Установка Python-зависимостей (бэкенд, автоматическое создание виртуального окружения)
npm run setup:backend
```

#### 3. Запуск сервисов

```bash
# Запуск фронтенда и бэкенда одновременно (из корня проекта)
npm run dev
```

**Адреса сервисов:**
- Фронтенд: `http://localhost:3000`
- Backend API: `http://localhost:5001`

**Запуск по отдельности:**

```bash
npm run backend   # Запустить только бэкенд
npm run frontend  # Запустить только фронтенд
```

### Вариант 2: Развёртывание через Docker

```bash
# 1. Настройка переменных окружения (как при развёртывании из исходного кода)
cp .env.example .env

# 2. Скачивание образа и запуск
docker compose up -d
```

По умолчанию считывает `.env` из корневой директории, пробрасывает порты `3000 (фронтенд) / 5001 (бэкенд)`

> Адрес зеркала для более быстрой загрузки указан в комментариях в `docker-compose.yml`, при необходимости замените.
