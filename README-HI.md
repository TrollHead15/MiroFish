## ⚡ अवलोकन

**MiroFish** एक अगली पीढ़ी का एआई भविष्यवाणी इंजन है जो मल्टी-एजेंट तकनीक पर आधारित है। वास्तविक दुनिया से बीज जानकारी (जैसे ब्रेकिंग न्यूज़, नीति मसौदे, या वित्तीय संकेत) निकालकर, यह स्वचालित रूप से एक उच्च-निष्ठा समानांतर डिजिटल दुनिया का निर्माण करता है। इस स्थान के भीतर, हजारों बुद्धिमान एजेंट स्वतंत्र व्यक्तित्व, दीर्घकालिक स्मृति और व्यवहारिक तर्क के साथ स्वतंत्र रूप से बातचीत करते हैं और सामाजिक विकास से गुजरते हैं। आप "ईश्वरीय दृष्टिकोण" से चरों को गतिशील रूप से इंजेक्ट कर सकते हैं ताकि भविष्य की दिशाओं को सटीक रूप से अनुमानित किया जा सके — **डिजिटल सैंडबॉक्स में भविष्य का अभ्यास करें, और अनगिनत सिमुलेशन के बाद निर्णय जीतें**।

> आपको केवल इतना करना है: बीज सामग्री अपलोड करें (डेटा विश्लेषण रिपोर्ट या दिलचस्प उपन्यास कहानियाँ) और प्राकृतिक भाषा में अपनी भविष्यवाणी आवश्यकताओं का वर्णन करें</br>
> MiroFish वापस देगा: एक विस्तृत भविष्यवाणी रिपोर्ट और गहराई से इंटरैक्टिव उच्च-निष्ठा डिजिटल दुनिया

### हमारी दृष्टि

MiroFish वास्तविकता को मैप करने वाले एक स्वार्म इंटेलिजेंस दर्पण को बनाने के लिए समर्पित है। व्यक्तिगत बातचीत से उत्पन्न सामूहिक उभार को पकड़कर, हम पारंपरिक भविष्यवाणी की सीमाओं को तोड़ते हैं:

- **मैक्रो स्तर पर**: हम निर्णय लेने वालों के लिए एक रिहर्सल प्रयोगशाला हैं, जहाँ नीतियों और जनसंपर्क को शून्य जोखिम पर परखा जा सकता है
- **माइक्रो स्तर पर**: हम व्यक्तिगत उपयोगकर्ताओं के लिए एक रचनात्मक सैंडबॉक्स हैं — चाहे उपन्यास के अंत का अनुमान लगाया जाए या काल्पनिक परिदृश्यों का पता लगाया जाए, सब कुछ मज़ेदार, खेलने योग्य और सुलभ हो सकता है

गंभीर भविष्यवाणियों से लेकर खेल सिमुलेशन तक, हम हर "क्या हो अगर" को उसका परिणाम देखने देते हैं, जिससे कुछ भी भविष्यवाणी करना संभव हो जाता है।

## 🚀 त्वरित आरंभ

### विकल्प 1: सोर्स कोड डिप्लॉयमेंट (अनुशंसित)

#### पूर्वापेक्षाएँ

| टूल | संस्करण | विवरण | इंस्टॉलेशन जाँच |
|------|---------|-------------|-------------------|
| **Node.js** | 18+ | फ्रंटएंड रनटाइम, npm शामिल | `node -v` |
| **Python** | ≥3.11, ≤3.12 | बैकएंड रनटाइम | `python --version` |
| **uv** | नवीनतम | Python पैकेज मैनेजर | `uv --version` |

#### 1. पर्यावरण चर कॉन्फ़िगर करें

```bash
# उदाहरण कॉन्फ़िगरेशन फ़ाइल कॉपी करें
cp .env.example .env

# .env फ़ाइल संपादित करें और आवश्यक API कुंजियाँ भरें
```

**आवश्यक पर्यावरण चर:**

```env
# LLM API कॉन्फ़िगरेशन (OpenAI SDK प्रारूप वाला कोई भी LLM API समर्थित)
# अनुशंसित: Bailian प्लेटफ़ॉर्म के माध्यम से Alibaba Qwen-plus मॉडल: https://bailian.console.aliyun.com/  
# उच्च खपत, पहले 40 से कम राउंड के साथ सिमुलेशन आज़माएँ
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1  
LLM_MODEL_NAME=qwen-plus

# Zep Cloud कॉन्फ़िगरेशन
# मुफ्त मासिक कोटा सरल उपयोग के लिए पर्याप्त है: https://app.getzep.com/  
ZEP_API_KEY=your_zep_api_key
```

#### 2. निर्भरताएँ इंस्टॉल करें

```bash
# सभी निर्भरताओं की वन-क्लिक इंस्टॉलेशन (root + फ्रंटएंड + बैकएंड)
npm run setup:all
```

या चरण-दर-चरण इंस्टॉल करें:

```bash
# Node निर्भरताएँ इंस्टॉल करें (root + फ्रंटएंड)
npm run setup

# Python निर्भरताएँ इंस्टॉल करें (बैकएंड, ऑटो-वर्चुअल एनवायरनमेंट बनाता है)
npm run setup:backend
```

#### 3. सर्विसेज़ शुरू करें

```bash
# फ्रंटएंड और बैकएंड दोनों शुरू करें (प्रोजेक्ट रूट से चलाएँ)
npm run dev
```

**सर्विस URL:**
- फ्रंटएंड: `http://localhost:3000`
- बैकएंड API: `http://localhost:5001`

**अलग-अलग शुरू करें:**

```bash
npm run backend   # केवल बैकएंड शुरू करें
npm run frontend  # केवल फ्रंटएंड शुरू करें
```

### विकल्प 2: Docker डिप्लॉयमेंट

```bash
# 1. पर्यावरण चर कॉन्फ़िगर करें (सोर्स डिप्लॉयमेंट की तरह)
cp .env.example .env

# 2. इमेज पुल करें और शुरू करें
docker compose up -d
```

डिफ़ॉल्ट रूप से रूट डायरेक्टरी से `.env` पढ़ता है, पोर्ट मैप करता है `3000 (फ्रंटएंड) / 5001 (बैकएंड)`

> तेज़ पुलिंग के लिए मिरर एड्रेस `docker-compose.yml` में टिप्पणियों के रूप में प्रदान किया गया है, यदि आवश्यक हो तो बदलें।
